# TEKKEN: Dark Resurrection - Web Edition (60 FPS)

🌐 **Sitio Web en Vivo:** [https://tekken-web.vercel.app/](https://tekken-web.vercel.app/)

Juega **Tekken: Dark Resurrection** 100% en tu navegador web a 60 FPS con WebAssembly (WASM), WebGL2 y soporte completo de mandos (Gamepad API).

## 🚀 Características
- **100% Web:** No requiere instalar programas ni emuladores en tu PC.
- **Modo Kiosk / Pantalla Limpia:** Sin botones táctiles transparentes ni menús estorbando.
- **Soporte de Mandos:** Compatible con mandos de Xbox, PlayStation y genéricos vía Web Gamepad API.
- **Caché Local:** Guarda el juego en la memoria caché del navegador (Cache API) para cargas instantáneas.
- **Soporte Vercel & Cloudflare Pages:** Configurado con cabeceras `COOP` / `COEP` para WebAssembly multihilo (`SharedArrayBuffer`).

## 🎮 Controles
- **Movimiento:** Flechas del teclado / D-Pad del mando
- **Cruz (✕ / Confirmar):** `Z` o `Espacio` / Botón `A` en Xbox / `✕` en PlayStation
- **Círculo (○ / Cancelar):** `X` o `C` / Botón `B` en Xbox / `○` en PlayStation
- **Cuadrado (□ / Golpe Izquierdo):** `A` / Botón `X` en Xbox / `□` en PlayStation
- **Triángulo (△ / Golpe Derecho):** `S` / Botón `Y` en Xbox / `△` en PlayStation
- **L-Trigger:** `Q` / Botón `LB`
- **R-Trigger:** `W` / Botón `RB`
- **START:** `Enter` / Botón `Start`
- **SELECT:** `Shift` / Botón `Select`
